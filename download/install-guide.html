🏫 학교별 설치본

초등 반별 시간표 만들기
설치 안내

우리 학교 저장소를 만들어 연결하는 과정입니다. 프로그램을 설치하거나 서버를 사지 않아도 되고, 모두 무료입니다. setup.html의 설치 마법사를 따라가면 처음 하셔도 30분이면 끝납니다.

왜 학교가 직접 설치하나요?
시간표에는 우리 학교의 학급 구성과 담당 교사 정보가 담깁니다. 이 자료가 만든이의 서버에 모이면 만든이가 개인정보 수탁자가 됩니다. 학교가 자기 저장소에 설치하면 자료가 학교 밖으로 나가지 않고, 관리 책임도 명확해집니다.

교원 자율연수비 정산 시스템을 설치해 보셨다면 순서가 같습니다. 한 가지만 다릅니다. 반별 시간표는 익명 로그인(4단계)을 켜야 합니다. 같은 Firebase 프로젝트를 함께 써도 되고, 따로 만들어도 됩니다.
1
준비물 확인
2분
  • 구글 계정 하나 — 학교 공용 계정을 권합니다. 담당자가 바뀌어도 이어받을 수 있습니다.
  • 깃허브(GitHub)·버셀(Vercel) 계정 — 완성한 파일을 인터넷에 올릴 때 씁니다. 구글 계정으로 가입할 수 있습니다.
  • 파일 두 개 — setup.html(설치 파일)과 이 안내서. 같은 폴더에 두세요.
개인 구글 계정은 피해 주세요. 전보를 가시면 학교가 자료에 접근할 수 없게 됩니다. 학교 업무용 계정으로 만들고, 인수인계 문서에 계정과 이 안내를 함께 남겨 주세요.
2
Firebase 프로젝트 만들기
5분

Firebase는 구글이 제공하는 무료 저장소입니다. 학교 규모에서는 요금이 나올 일이 없습니다.

  1. console.firebase.google.com 에 학교 구글 계정으로 접속합니다.
  2. [프로젝트 만들기]를 누릅니다.
  3. 프로젝트 이름을 적습니다. 예: unnam-timetable
    영문·숫자·하이픈만 쓸 수 있습니다.
  4. Google 애널리틱스는 꺼 두셔도 됩니다. 이 프로그램은 쓰지 않습니다.
  5. [프로젝트 만들기]를 누르고 1분쯤 기다립니다.
3
Firestore 데이터베이스 만들기
3분
  1. 왼쪽 메뉴에서 데이터베이스 및 스토리지 → Firestore를 고릅니다.
  2. [데이터베이스 만들기]를 누릅니다.
  3. 위치는 asia-northeast3 (서울)을 고릅니다.
    위치는 나중에 바꿀 수 없습니다. 반드시 서울로 고르세요. 그리고 이 값을 적어 두세요 — 개인정보 처리방침에 저장 지역으로 적어야 합니다.
  4. 보안 규칙은 프로덕션 모드로 시작합니다. (7단계에서 제대로 된 규칙을 넣습니다)
4
익명 로그인 켜기
2분

선생님들이 아이디를 만들지 않고도 쓸 수 있도록, 브라우저마다 이름 없는 번호를 하나씩 받는 방식입니다. 개인정보를 받지 않으면서도 “누가 우리 학교 사람인지”를 가릴 수 있게 해 줍니다.

  1. 왼쪽 메뉴에서 보안 → Authentication을 고릅니다.
  2. [시작하기]를 누릅니다.
  3. 로그인 방법 탭에서 익명을 찾아 누릅니다.
  4. 사용 설정을 켜고 저장합니다.
이 단계를 빠뜨리면 학교를 만들 때 “네트워크 인증에 실패했습니다”가 뜹니다. 가장 흔한 실수입니다. 설치 마법사가 켜졌는지 확인해 알려 드립니다.
5
웹 앱 추가하고 설정값 복사하기
3분
  1. 왼쪽 위 설정 → 일반을 누릅니다.
  2. 아래로 내려 내 앱에서 </> (웹) 아이콘을 누릅니다.
  3. 앱 이름을 적고(예: 시간표) [앱 등록]을 누릅니다. 호스팅 설정은 체크하지 않아도 됩니다.
  4. const firebaseConfig = { … }가 나옵니다. 중괄호 부분을 통째로 복사합니다.
이 값이 공개되어도 괜찮나요? 괜찮습니다. 웹 앱의 주소 같은 값이라 원래 공개됩니다. 실제 보안은 7단계의 보안 규칙이 담당합니다.
6
setup.html 열어 설정 붙여 넣기
3분
  1. 내려받은 setup.html을 더블클릭해 크롬 브라우저로 엽니다. (인터넷은 연결되어 있어야 합니다)
  2. 설치 마법사 화면이 나옵니다. 3번 칸에 방금 복사한 설정을 붙여 넣습니다.
  3. [🔍 설정 확인하기]를 누릅니다. 연결되면 4~6단계가 이어서 나타납니다.
  4. 4단계에서 Firestore와 익명 로그인이 모두 ✅인지 봅니다. ⚠️가 보이면 그 기능을 켠 뒤 [설정 확인하기]를 한 번 더 누르세요.
파일을 편집기로 열어 고칠 필요가 없습니다. 마법사가 값을 넣은 파일을 만들어 줍니다.
7
보안 규칙 붙여넣고 게시하기 — 가장 중요
3분
이 단계를 건너뛰면 누구나 우리 학교 자료를 읽고 지울 수 있습니다. 반드시 [게시]까지 마쳐 주세요.
  1. 마법사의 [📋 보안 규칙 복사]를 누릅니다.
  2. [규칙 탭 열기]로 이동해 Firestore → 규칙 칸의 내용을 지우고 통째로 붙여 넣습니다.
  3. [게시]를 누릅니다.
복사 단추가 동작하지 않을 때 — 규칙 전문 보기 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() {
      return request.auth != null;
    }
    // 이 학교의 접속 자격(members 문서)을 가지고 있는가
    function isMember(sid) {
      return signedIn() && exists(
        /databases/$(database)/documents/schools/$(sid)/members/$(request.auth.uid)
      );
    }
    // 저장된 비밀번호 해시
    function secretOf(sid) {
      return get(
        /databases/$(database)/documents/schools/$(sid)/secret/auth
      ).data;
    }
    function secretExists(sid) {
      return exists(
        /databases/$(database)/documents/schools/$(sid)/secret/auth
      );
    }

    // 학교 이름 색인 — 이름 하나로 정확히 찾을 때만 쓴다
    match /nameIndex/{key} {
      allow get:    if signedIn();
      allow list:   if false;          // 학교 목록 통째로 보기 금지
      allow create: if signedIn();
      allow update, delete: if signedIn();
    }

    match /schools/{sid} {
      allow get:    if isMember(sid);
      allow list:   if false;          // 학교 목록 통째로 보기 금지
      allow create, update, delete: if isMember(sid);

      // 비밀번호 해시 — 아무도 읽지 못한다
      match /secret/{docId} {
        allow read:   if false;
        allow create: if signedIn() && !secretExists(sid);
        allow update, delete: if isMember(sid);
      }

      // 접속 자격 — 비밀번호가 맞아야만 만들 수 있다
      match /members/{uid} {
        allow get:  if signedIn() && request.auth.uid == uid;
        allow list: if isMember(sid);
        allow create, update: if signedIn()
          && request.auth.uid == uid
          && (
            // 학교를 처음 만드는 순간
            !secretExists(sid)
            // 관리자 비밀번호가 맞을 때
            || (request.resource.data.role == 'admin'
                && request.resource.data.h == secretOf(sid).adminHash)
            // 교사 비밀번호가 맞을 때
            || (request.resource.data.role == 'teacher'
                && request.resource.data.h == secretOf(sid).teacherHash)
          );
        allow delete: if signedIn();
      }

      // 각 반 시간표
      match /timetables/{classId} {
        allow read, write: if isMember(sid);
      }
    }
  }
}

이 규칙이 막아 주는 것

상황결과
비밀번호를 모르는 사람이 주소만 알고 들어옴학교 자료를 읽을 수 없음
등록된 학교 목록을 통째로 보려고 시도차단됨 (list 금지)
저장된 비밀번호를 읽으려고 시도차단됨. 게다가 원문이 아니라 되돌릴 수 없는 해시만 저장됨
다른 학교 자료에 접근그 학교의 접속 자격이 없으므로 차단됨
8
완성된 index.html 내려받기
1분

마법사 6단계의 [⬇ 설정이 끝난 index.html 내려받기]를 누릅니다. 우리 학교 설정이 모두 들어간 index.html 한 개가 저장됩니다. 이 파일이 우리 학교 프로그램입니다.

setup.html은 설치용이라 올리지 않으셔도 됩니다. 나중에 다시 설치할 일이 있을 수 있으니 컴퓨터에 보관해 두세요.
9
인터넷에 올리기
10분

교원 자율연수비 정산 시스템과 같은 방법입니다. 파일 하나뿐이라 어디에 올려도 됩니다.

깃허브(GitHub)에 파일 올리기

  1. github.com에서 [Create repository]로 새 저장소를 만듭니다. 이름은 timetable처럼 영문으로 정하고, Public으로 둡니다.
  2. [uploading an existing file]을 눌러 8단계에서 받은 index.html을 끌어다 놓고 [Commit changes]를 누릅니다.

버셀(Vercel)로 주소 만들기

  1. vercel.com에서 [Add New → Project]를 누릅니다.
  2. 깃허브를 연결하고, 방금 만든 저장소를 찾아 [Import] → [Deploy]를 누릅니다.
  3. [Domains] 아래에 나온 주소가 우리 학교 시간표 주소입니다.
✅ 여기까지 하시면 설치가 끝났습니다. 파이어베이스로 돌아가 따로 등록할 것은 없습니다.
저장소가 Public이어도 자료가 공개되는 것이 아닙니다. 공개되는 것은 프로그램 파일뿐이고, 시간표 자료는 우리 학교 Firebase에 들어 있으며 보안 규칙과 비밀번호로 막혀 있습니다.
학교 홈페이지나 GitHub Pages·Netlify 같은 다른 곳에 올리셔도 됩니다.
완성된 index.html을 더블클릭해서 쓰는 방식(file://)은 피해 주세요. 선생님들이 함께 쓰려면 인터넷에 올려 https:// 주소로 들어가야 합니다.
10
첫 사용 — 학교 만들고 선생님께 안내
10분
  1. 올린 주소로 들어가 [✨ 새 학교(그룹) 만들기]를 누릅니다.
  2. 학교 이름과 비밀번호를 정합니다.
    비밀번호를 잃어버리면 되살릴 수 없습니다. 원문을 저장하지 않기 때문입니다. 업무 인수인계 문서에 꼭 적어 두세요.
  3. 기초 설정에서 학급 구성 → 교시 시간 → 교과전담 → 특별실 → 교과 시수를 입력합니다.
    교과전담은 실명 대신 ‘과학 전담’처럼 담당 표기를 권합니다.
  4. 특별실 배정에서 강당·과학실 등을 학급별로 배정합니다.
  5. 선생님들께 주소·학교 이름·비밀번호를 안내합니다.

선생님들께 보낼 안내문 예시

[시간표 작성 안내]

아래 주소에서 우리 반 시간표를 직접 입력해 주세요.

· 주소: https://(우리 학교 주소)
· 학교 이름: (만든 학교 이름)
· 비밀번호: (정한 비밀번호)

접속 → 학교 이름·비밀번호 입력 → 역할에서 '담임교사'
→ 담당 학급 선택 → 시간표 입력

교과전담 시간은 이미 채워져 있으니 나머지만 넣으시면 됩니다.
다 하시면 따로 저장을 누르지 않아도 자동으로 반영됩니다.

문의: (담당자)

개인정보 처리방침 채우기

화면 맨 아래 [개인정보] 버튼에 처리방침이 들어 있습니다. 학교마다 달라지는 곳을 [ ]로 비워 두었으니 채워 주세요.

12
문제가 생겼을 때
증상확인할 것
올린 주소에 설치 마법사가 뜬다 setup.html을 올리셨거나, 8단계에서 받은 파일이 아닌 것을 올리셨습니다. 마법사에서 내려받은 index.html을 올려 주세요.
설치 마법사에서 “연결하지 못했습니다” 설정값을 중괄호 { }까지 통째로 붙여 넣으셨는지 확인하세요.
마법사에서 Firestore가 ⚠️ 3단계 데이터베이스 만들기를 먼저 해 주세요.
마법사에서 익명 로그인이 ⚠️ · “네트워크 인증에 실패했습니다” 4단계 익명 로그인이 꺼져 있습니다.
화면이 하얗게만 나온다 인터넷 연결을 확인하세요. 학교 방화벽이 gstatic.com, cdnjs.cloudflare.com을 막고 있으면 열리지 않을 수 있습니다.
학교는 만들어지는데 내용이 저장되지 않는다 7단계 보안 규칙을 [게시]까지 눌렀는지 확인하세요.
“학교 이름 또는 비밀번호가 맞지 않습니다” 학교 이름은 띄어쓰기를 무시하지만 글자는 정확해야 합니다. 비밀번호를 잊으셨다면 새 학교를 만들고 백업을 불러오세요.
선생님이 입력한 게 관리자 화면에 안 보인다 새로고침해 보세요. 그래도 안 되면 같은 주소·같은 학교 이름으로 접속했는지 확인하세요.

이 안내서는 Pretendard 글꼴만 사용하며, 설치하시는 초등 반별 시간표 만들기(index.html)는 아래 오픈소스 글꼴·라이브러리를 외부 CDN에서 불러와 사용합니다. 각 저작권자에게 감사드리며, 라이선스 조건에 따라 저작권 표시와 라이선스 전문을 함께 고지합니다. 「└」로 표시한 것은 Firebase·ExcelJS 스크립트 파일 안에 함께 묶여 배포되는 구성요소입니다. JSZip은 MIT/GPLv3 이중 라이선스 중 MIT 조건으로 이용합니다.
