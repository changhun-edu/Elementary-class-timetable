설치 안내

우리 학교 저장소를 만들어 연결하는 과정입니다. 프로그램을 설치하거나 서버를 사지 않아도 되고, 모두 무료입니다. 처음 하시면 30분쯤 걸립니다.

왜 학교가 직접 설치하나요?
시간표에는 우리 학교의 학급 구성과 담당 교사 정보가 담깁니다. 이 자료가 만든이의 서버에 모이면 만든이가 개인정보 수탁자가 됩니다. 학교가 자기 저장소에 설치하면 자료가 학교 밖으로 나가지 않고, 관리 책임도 명확해집니다.

1
준비물 확인
2분
  • 구글 계정 하나 — 학교 공용 계정을 권합니다. 담당자가 바뀌어도 이어받을 수 있습니다.
  • index.html 파일 — 이 안내와 함께 받은 파일입니다.
  • 메모장 같은 텍스트 편집기 — 윈도우 기본 메모장으로 충분합니다.
개인 구글 계정은 피해 주세요. 전보를 가시면 학교가 자료에 접근할 수 없게 됩니다. 학교 업무용 계정으로 만들고, 인수인계 문서에 계정과 이 안내를 함께 남겨 주세요.
2
Firebase 프로젝트 만들기
5분

Firebase는 구글이 제공하는 무료 저장소입니다. 학교 규모에서는 요금이 나올 일이 없습니다.

  1. console.firebase.google.com 에 학교 구글 계정으로 접속합니다.
  2. [프로젝트 만들기]를 누릅니다.
  3. 프로젝트 이름을 적습니다. 예: unnam-timetable
    영문·숫자·하이픈만 쓸 수 있습니다. 이름은 나중에 바꿔도 됩니다.
  4. Google 애널리틱스는 꺼 두셔도 됩니다. 이 프로그램은 쓰지 않습니다.
  5. [프로젝트 만들기]를 누르고 1분쯤 기다립니다.
3
Firestore 데이터베이스 만들기
3분
  1. 왼쪽 메뉴에서 빌드 → Firestore Database를 고릅니다.
  2. [데이터베이스 만들기]를 누릅니다.
  3. 위치는 asia-northeast3 (서울)을 고릅니다.
    위치는 나중에 바꿀 수 없습니다. 반드시 서울로 고르세요. 그리고 이 값을 적어 두세요 — 개인정보 처리방침에 저장 지역으로 적어야 합니다.
  4. 보안 규칙은 프로덕션 모드로 시작합니다. (6단계에서 제대로 된 규칙을 넣습니다)
4
익명 로그인 켜기
2분

선생님들이 아이디를 만들지 않고도 쓸 수 있도록, 브라우저마다 이름 없는 번호를 하나씩 받는 방식입니다. 개인정보를 받지 않으면서도 “누가 우리 학교 사람인지”를 가릴 수 있게 해 줍니다.

  1. 왼쪽 메뉴에서 빌드 → Authentication을 고릅니다.
  2. [시작하기]를 누릅니다.
  3. 로그인 방법 탭에서 익명을 찾아 누릅니다.
  4. 사용 설정을 켜고 저장합니다.
이 단계를 빠뜨리면 학교를 만들 때 “네트워크 인증에 실패했습니다”가 뜹니다. 가장 흔한 실수이니 꼭 확인해 주세요.
5
설정값 복사해 index.html에 넣기
5분
  1. 왼쪽 위 ⚙️ → 프로젝트 설정을 누릅니다.
  2. 아래로 내려 내 앱에서 </> (웹) 아이콘을 누릅니다.
  3. 앱 닉네임을 적고(예: 시간표) [앱 등록]을 누릅니다. 호스팅 설정은 체크하지 않아도 됩니다.
  4. 화면에 나오는 firebaseConfig 값을 전부 복사합니다.
  5. index.html을 메모장으로 엽니다. (파일 우클릭 → 연결 프로그램 → 메모장)
  6. Ctrl+F로 여기만 고치면 됩니다를 찾습니다.
  7. 따옴표 안을 복사한 값으로 채우고 저장합니다.

이렇게 생긴 부분입니다.

const firebaseConfig = {
  apiKey:            "AIzaSyD-여기에-우리학교-값",
  authDomain:        "unnam-timetable.firebaseapp.com",
  projectId:         "unnam-timetable",
  storageBucket:     "unnam-timetable.appspot.com",
  messagingSenderId: "123456789012",
  appId:             "1:123456789012:web:abcdef123456",
};
따옴표와 쉼표를 지우지 마세요. 따옴표 안쪽 글자만 바꾸면 됩니다. 하나라도 빠지면 화면이 하얗게 뜹니다.
이 값이 공개되어도 괜찮나요? 괜찮습니다. 웹 앱의 주소 같은 값이라 원래 공개됩니다. 실제 보안은 다음 단계의 보안 규칙이 담당합니다.
6
보안 규칙 붙여 넣기 — 가장 중요
5분
이 단계를 건너뛰면 누구나 우리 학교 자료를 읽고 지울 수 있습니다. 반드시 끝까지 하세요.
  1. Firestore Database → 규칙 탭을 엽니다.
  2. 기존 내용을 모두 지우고 아래를 붙여 넣습니다.
  3. [게시]를 누릅니다.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() {
      return request.auth != null;
    }
    // 이 학교의 접속 자격(members 문서)을 가지고 있는가
    function isMember(sid) {
      return signedIn() && exists(
        /databases/$(database)/documents/schools/$(sid)/members/$(request.auth.uid)
      );
    }
    // 저장된 비밀번호 해시
    function secretOf(sid) {
      return get(
        /databases/$(database)/documents/schools/$(sid)/secret/auth
      ).data;
    }
    function secretExists(sid) {
      return exists(
        /databases/$(database)/documents/schools/$(sid)/secret/auth
      );
    }

    // 학교 이름 색인 — 이름 하나로 정확히 찾을 때만 쓴다
    match /nameIndex/{key} {
      allow get:    if signedIn();
      allow list:   if false;          // 학교 목록 통째로 보기 금지
      allow create: if signedIn();
      allow update, delete: if signedIn();
    }

    match /schools/{sid} {
      allow get:    if isMember(sid);
      allow list:   if false;          // 학교 목록 통째로 보기 금지
      allow create, update, delete: if isMember(sid);

      // 비밀번호 해시 — 아무도 읽지 못한다
      match /secret/{docId} {
        allow read:   if false;
        allow create: if signedIn() && !secretExists(sid);
        allow update, delete: if isMember(sid);
      }

      // 접속 자격 — 비밀번호가 맞아야만 만들 수 있다
      match /members/{uid} {
        allow get:  if signedIn() && request.auth.uid == uid;
        allow list: if isMember(sid);
        allow create, update: if signedIn()
          && request.auth.uid == uid
          && (
            // 학교를 처음 만드는 순간
            !secretExists(sid)
            // 관리자 비밀번호가 맞을 때
            || (request.resource.data.role == 'admin'
                && request.resource.data.h == secretOf(sid).adminHash)
            // 교사 비밀번호가 맞을 때
            || (request.resource.data.role == 'teacher'
                && request.resource.data.h == secretOf(sid).teacherHash)
          );
        allow delete: if signedIn();
      }

      // 각 반 시간표
      match /timetables/{classId} {
        allow read, write: if isMember(sid);
      }
    }
  }
}

이 규칙이 막아 주는 것

상황결과
비밀번호를 모르는 사람이 주소만 알고 들어옴학교 자료를 읽을 수 없음
등록된 학교 목록을 통째로 보려고 시도차단됨 (list 금지)
저장된 비밀번호를 읽으려고 시도차단됨. 게다가 원문이 아니라 되돌릴 수 없는 해시만 저장됨
다른 학교 자료에 접근그 학교의 접속 자격이 없으므로 차단됨

인터넷에 올리기
10분

파일 하나뿐이라 어디에 올려도 됩니다. 쉬운 순서대로 적었습니다.

가장 쉬운 방법 — Netlify Drop

  1. app.netlify.com/drop 에 접속합니다.
  2. index.html이 든 폴더를 화면에 끌어다 놓습니다.
  3. 몇 초 뒤 주소가 나옵니다. 이 주소를 선생님들께 안내하면 끝입니다.
계정 없이도 올라가지만, 가입해 두면 나중에 파일을 고쳐 다시 올리거나 주소를 바꿀 수 있습니다.

8
첫 사용 — 학교 만들고 선생님께 안내
10분
  1. 올린 주소로 들어가 [✨ 새 학교(그룹) 만들기]를 누릅니다.
  2. 학교 이름과 비밀번호를 정합니다.
    비밀번호를 잃어버리면 되살릴 수 없습니다. 원문을 저장하지 않기 때문입니다. 업무 인수인계 문서에 꼭 적어 두세요.
  3. 기초 설정에서 학급 구성 → 교시 시간 → 교과전담 → 특별실 → 교과 시수를 입력합니다.
    교과전담은 실명 대신 ‘과학 전담’처럼 담당 표기를 권합니다.
  4. 특별실 배정에서 강당·과학실 등을 학급별로 배정합니다.
  5. 선생님들께 주소·학교 이름·비밀번호를 안내합니다.

선생님들께 보낼 안내문 예시

[시간표 작성 안내]

아래 주소에서 우리 반 시간표를 직접 입력해 주세요.

· 주소: https://(우리 학교 주소)
· 학교 이름: (만든 학교 이름)
· 비밀번호: (정한 비밀번호)

접속 → 학교 이름·비밀번호 입력 → 역할에서 '담임교사'
→ 담당 학급 선택 → 시간표 입력

교과전담 시간은 이미 채워져 있으니 나머지만 넣으시면 됩니다.
다 하시면 따로 저장을 누르지 않아도 자동으로 반영됩니다.

문의: (담당자)

개인정보 처리방침 채우기
5분

화면 맨 아래 [개인정보] 버튼에 처리방침이 들어 있습니다. 학교마다 달라지는 곳을 [ ]로 비워 두었으니 채워 주세요.

채울 곳적을 내용
저장 지역3단계에서 고른 위치 — 보통 asia-northeast3(서울)
보유 기간학교 기록물 기준에 맞춰. 예: 해당 학년도 종료 후 1년
개인정보 보호 책임자직위·성명
연락처학교 대표 전화 또는 업무용 이메일
소속학교명
시행일설치한 날짜

메모장에서 Ctrl+F로 [ 학교명 ]처럼 대괄호를 찾으면 빠르게 고칠 수 있습니다.

이 프로그램은 학생 정보를 전혀 입력받지 않습니다. 학생 이름이나 번호를 적는 칸이 아예 없습니다. 저장되는 것은 학급명(3-1), 교과목, 교시, 특별실, 시간표뿐입니다.
10
문제가 생겼을 때
증상확인할 것
설치 안내 화면이 계속 뜬다 5단계의 apiKey·projectId가 비어 있습니다. 저장했는지, 올린 파일이 고친 파일이 맞는지 확인하세요.
화면이 하얗게만 나온다 5단계에서 따옴표나 쉼표가 빠졌을 가능성이 큽니다. 붙여 넣은 부분을 다시 보세요.
“네트워크 인증에 실패했습니다” 4단계 익명 로그인이 꺼져 있습니다.
학교는 만들어지는데 내용이 저장되지 않는다 6단계 보안 규칙을 [게시]까지 눌렀는지 확인하세요.
“학교 이름 또는 비밀번호가 맞지 않습니다” 학교 이름은 띄어쓰기를 무시하지만 글자는 정확해야 합니다. 비밀번호를 잊으셨다면 새 학교를 만들고 백업을 불러오세요.
선생님이 입력한 게 관리자 화면에 안 보인다 새로고침해 보세요. 그래도 안 되면 같은 주소·같은 학교 이름으로 접속했는지 확인하세요.
